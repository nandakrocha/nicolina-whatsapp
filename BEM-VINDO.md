## 💾 **Modo Atual: Offline (LocalStorage)**

### Como funciona?
- Todos os dados são salvos **localmente no navegador**
- Funciona **sem internet**
- **100% privado** - dados nunca saem do seu dispositivo
- **Dados de exemplo** já incluídos para você testar

### Limitações do modo offline:
- ❌ Dados não são sincronizados entre dispositivos
- ❌ Se limpar o cache do navegador, os dados são perdidos
- ❌ Não há backup automático na nuvem

---

## 🌐 **Quer habilitar Sincronização em Tempo Real?**

### Com Supabase você terá:
- ✅ **Sincronização automática** entre tablets, computadores e celulares
- ✅ **Backup automático** na nuvem
- ✅ **Múltiplos usuários** trabalhando simultaneamente
- ✅ **Histórico completo** de alterações
- ✅ **99.9% de disponibilidade**
- ✅ **Dados seguros** e protegidos

### Como configurar (opcional):

1. **Criar conta gratuita no Supabase:**
   - Acesse: https://supabase.com
   - Plano gratuito: 500MB de banco de dados

2. **Criar um novo projeto:**
   - Nome: "Nicolina"
   - Região: South America (São Paulo)

3. **Copiar as credenciais:**
   - No painel do Supabase, vá em Settings → API
   - Copie: `URL` e `anon public key`

4. **Configurar variáveis de ambiente:**
   - Crie arquivo `.env` na raiz do projeto
   - Adicione:
   ```
   VITE_SUPABASE_URL=sua-url-aqui
   VITE_SUPABASE_ANON_KEY=sua-chave-aqui
   ```

5. **Executar script SQL:**
   - No Supabase, vá em SQL Editor
   - Execute o script que está no arquivo `supabase-setup.sql`

6. **Reiniciar o aplicativo:**
   - Recarregue a página
   - Verá mensagem "✅ Modo Online - Sincronização ativa"
